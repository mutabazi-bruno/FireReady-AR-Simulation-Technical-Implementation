# Credits

Third-party assets used in FireReady AR. Each asset sits in its own folder under
`Assets/FireReady/ThirdParty/` so it is easy to see what came from where.

## 3D models

| Asset | Author | Source | License | Used for |
|---|---|---|---|---|
| Realistic Fire Extinguisher - Low Poly | Renend Studio | [Sketchfab](https://sketchfab.com/3d-models/realistic-fire-extinguisher-low-poly-7bc661f26edc487d9b6182a9efa97b7a) | Sketchfab Free Standard | All four extinguishers (the agent band and label are added in Unity) |
| Furniture Pack 1.0 (desk, desk chair, computer screen, keyboard, trash can, bookcase, potted plant, doorway) | Kenney | [kenney.nl](https://kenney.nl/assets/furniture-kit) | CC0 | Office furniture, waste bin, exit door frame |

## Made for this project

UI icons, rounded UI shapes, particle textures for the spray and steam, the floor and hazard
textures, the generator, fuel can, alarm call point, power breaker and extension board models,
and these sounds: extinguisher spray, alarm bell, steam, spray sizzle, distance warning beep,
session success and fail jingles.

## Packages

Unity AR Foundation, Google ARCore XR Plugin, Addressables, Universal Render Pipeline,
TextMesh Pro (LiberationSans font, SIL Open Font License) and glTFast (for loading the `.glb`
extinguisher model).
