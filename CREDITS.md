# Credits

Third-party assets used in FireReady AR. Each asset sits in a folder named after its source under
`Assets/FireReady/ThirdParty/`, so it is easy to see what came from where. Some models were trimmed
or reduced in Blender so they run well on a phone; those changes are listed in the last column.

## Made for this project

UI shapes, background grid and corner brackets, the spray and steam particle textures, the alarm
post, breaker switch, exit door frame, fuel can and extinguisher stand, and these sounds: spray
sizzle, distance warning beep, session success and fail jingles.

## Packages

Unity AR Foundation, Google ARCore XR Plugin, Addressables, Universal Render Pipeline,
TextMesh Pro and glTFast (for loading the `.glb` models).
